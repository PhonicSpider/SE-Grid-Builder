# Changelog

Newest version first. One line per change, starting with Added, Adjusted or Fixed.

## ChangeLog V1.0.2
- Adjusted the block list to follow the order of the game's own block menu, in every category
- Added groups to blocks, so a block and its shapes (slopes, corners) share one tile like in the game
- Added a tooltip beside the cursor listing the blocks in a group as you hover over it
- Added a toolbar at the bottom of the viewport showing the selectable blocks when a group is chosen
- Added a first-launch tutorial that highlights each part of the app, with a "?" button to show it again
- Adjusted the "Include armor shapes and variants" option to "Include blocks the game hides from its menu"
- Added the new logo to the application, the installer and the README

## ChangeLog V1.0.1
- Fixed placement of multi-cell blocks on the grid so they sit on the face of the block the cursor is aimed at
- Added an updater and update check at the start of the loading process
