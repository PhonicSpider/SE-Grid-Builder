## Fixed in the rest of the Rust
| Finding | Fix |
|---|---|
| **Vertex positions ignored the per-vertex scale**, so big models were too small with spiky curved surfaces. Found by comparing the render with the game's icon. | Positions are x, y, z times the fourth number. All 1,369 models now match their stored bounding box (test). See [[MWM Model Format]]. |
| The install folder was searched for again on every icon and model request (hundreds per session). | Found once, remembered (`OnceLock`); a failed search is not remembered. |
| The catalog loaded on the window's own thread and froze the window for about a second at start-up. | `load_se1_catalog` is now `async` on a helper thread; a shared `run_in_background` removes the repeated error handling in all three slow commands. |
| `MwmFile::parse` copied the whole file for no reason. | Moved instead of cloned. |
| Reads from model files could run past the end or trust huge counts. | Every read is bounds-checked and returns an error; counts are capped; every index must point at a real vertex. A test cuts and damages a real file thousands of ways: always an error or the exact original mesh. |
| Paths from the front-end reach the disk. | One strict resolver (`resolve_content_file`) for icons and models: right extension, plain folder names only, final location inside `Content`. Tested with traversal attempts. |
| Clippy and dead code. | All warnings fixed (0 now); a test-only function is marked `#[cfg(test)]`. |

## How the accuracy was checked (so you can repeat it)
1. A Rust tool (`export_viewer_fixtures`, on demand) writes real models and game icons to a temporary `devfixtures/` folder.
2. A browser test page draws them with the app's real viewer code beside the game's icons: the reactor, cockpit and refinery match.
3. A second test page rebuilds a game-authored blueprint (`Miner`) from its `bp.sbc`, and checks that every rotated model stays inside its block's footprint: 40 of 40, over 15 orientations.
4. Tests compare against the data inside the game's own files (`ModelInfo` counts, stored `BoundingBox`).
The temporary folder and pages are deleted when finished; the tool stays (see [[Commands]]).
